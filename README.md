## 🚀 About Me

Hello! I'm **Sk Mazhar**, a passionate **AI Engineer and Full Stack Developer** dedicated to building intelligent, scalable, and real-world software applications. I specialize in designing robust backend systems using **FastAPI** and **Python**, training and deploying **Machine Learning** models, and leveraging state-of-the-art **AI Agents** to automate complex tasks.

- 🤖 **AI & Software Passion**: Crafting intelligent systems that bridge the gap between complex algorithms and practical, user-centric software.
- 💻 **Clean Code & Architecture**: Firm believer in writing readable, maintainable, and highly optimized code following best practices (SOLID, DRY).
- 🧩 **Problem Solving**: Enthusiastic about dissecting complex business requirements and transforming them into robust APIs and data pipelines.
- 📚 **Continuous Learning**: Constantly exploring emerging technologies like LangGraph, LLMs, and RAG architectures to stay at the cutting edge of AI.
